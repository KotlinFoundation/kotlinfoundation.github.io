The Kotlin Foundation’s Ecosystem Committee is pleased to announce the five projects selected for the 2026 Kotlin Foundation Grants Program.

This year’s recipients address everyday needs across the Kotlin ecosystem, from dependency management and testing to local AI, camera functionality, and file handling. The projects were selected for the problems they solve, the quality of their implementation, and their proposals for further development.

Each selected project will receive a $6,000 grant to support its proposed improvements and continued development.

### 2026 Grant Recipients

Meet the five projects and the work outlined in their grant proposals:

#### [Dependency Analysis Gradle Plugin](https://github.com/autonomousapps/dependency-analysis-gradle-plugin)

A Gradle plugin that analyzes dependencies in JVM and Android builds, helping developers find unused dependencies and improve their declarations.

**The proposal:** Expand Kotlin Multiplatform support beyond Android and JVM, starting with iOS and then other targets.

#### [Llamatik](https://github.com/llamatik/Llamatik)

An on-device AI SDK for Kotlin Multiplatform, with capabilities for running language models, speech-to-text, and image generation.

**The proposal:** Develop a broader SDK for local AI applications and agent workflows, improve native runtime integration and platform support, and strengthen API stability, documentation, testing, and CI.

#### [FileKit](https://github.com/vinceglb/FileKit)

A Kotlin Multiplatform library that provides consistent APIs for file operations and native file pickers across mobile, desktop, and web.

**The proposal:** Bring FileKit to 1.0 through a public API review, compatibility and deprecation policies, broader regression testing, improved documentation and migration guidance, and a release candidate informed by user feedback.

#### [Kamera](https://github.com/Kashif-E/Kamera)

A camera library for Compose Multiplatform with a shared API for Android, iOS, and JVM desktop.

**The proposal:** Review and document the public API, improve desktop reliability and permission handling, expand automated testing and CI, and stabilize and document the plugin system.

#### [JUnit](https://github.com/junit-team/junit-framework)

A testing framework for Java and the JVM, developed by The JUnit Team, that also supports Kotlin tests.

**The proposal:** Add experimental support for top-level Kotlin test functions, with discovery and execution through the Console Launcher, and companion object lifecycle hooks without @JvmStatic, alongside user guide updates.
